# CampusDudes

A collaborative learning and innovation platform designed to help MCA students build Git confidence, pitch stronger ideas, and ship polished hackathon projects.

## What this repository is becoming
This repository was originally a simple GitHub practice repo. For hackathon impact, we are evolving it into a campus-ready product concept with:

- A modern HTML/CSS/JS landing experience
- A stronger developer profile and project scoring story
- Better code organization and modular architecture
- A more polished C++ and C codebase with cleaner examples

## Hackathon positioning
We are maximizing points across the four judging criteria:

- Innovation: turn learning + campus collaboration into a practical system
- Technical Complexity: modular scoring and project metrics engine
- UI/UX: modern landing page, visual hierarchy, clear experience flow
- Real-World Impact: create value for students and campus teams

## Repository structure
- `Hisfile.html` — product landing page and showcase
- `assets/styles.css` — polished visual system and responsiveness
- `assets/script.js` — interactive UI enhancements
- `src/campus_logic.h` — modular scoring logic
- `src/campus_logic.cpp` — project evaluation engine
- `iMcol.cpp` — improved C++ profile and contact input example
- `practice.c` — campus project readiness example in C
- `docs/architecture.md` — architecture and product roadmap

## Recommended architecture
The optimal approach for a hackathon is a hybrid structure:

- Frontend: interactive static marketing page + dashboard-like sections
- Logic layer: reusable C++ scoring engine for judging metrics
- Data layer: lightweight JSON or in-memory metrics for project evaluation
- UX layer: responsive, gradient-heavy, card-based interface for visual storytelling

## Suggested next steps

2. Add a Git learning simulator or challenge leaderboard.
